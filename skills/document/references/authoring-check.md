# Document authoring check

<a id="authoring-check"></a>

## 1. Authoring check

- Before authoring, MUST apply [wording and revision](../../convention/references/prompting.md#concise-wording)
  and [context composition](../../convention/references/prompting.md#prompt-composition).
  Reuse loaded guidance; provider-specific rules apply only when relevant.
- Before completion, check:
  1. Meaning, actor, obligation, negation, conditions, exceptions and source fidelity.
  2. [Current/history boundaries](specification.md#current-and-history), unresolved choices and current limitations.
  3. [Section purpose](../../convention/references/prompting.md#section-scope), one rule owner, concise entries and scoped references.
  4. Selected language, technical wording, [visual placement](../../convention/references/prompting.md#section-table-order),
     type-specific metadata/assets, links and source ownership.
- Fix in-scope violations or report exact unmet checks and limitations. Format/sync success
  cannot establish compliance. No separate checklist or copied convention body is required.
